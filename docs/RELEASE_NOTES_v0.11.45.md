# v0.11.45 — GitHub 이슈 #28~#33 수정

이번 릴리스는 기존 작업 폴더에서 이어받은 컴플리트 박스 빌드를 기준으로,
열린 이슈를 원문 이미지·실행파일·이벤트 스크립트까지 대조해 수정한 버전입니다.

## 해결한 이슈

- **#28 EX 슈우장 개방시** — v0.11.40에서 고친 128바이트 대사 스택 초과 문제를
  EX 및 제3차 관련 대사 페이지 게이트로 다시 검증했습니다. 128바이트를 넘는
  페이지는 없으며, 이슈의 프리즈 증상은 재현되지 않아 닫았습니다.
- **#29 정신기 표기 오류** — EX 정신기 표의 잘못된 `F0 62 FF` 글리프를 `혼`으로
  교정했습니다. 최종 EX 실행파일에서 해당 잘못된 레코드는 0건입니다.
- **#30 EX 슈우장 개방시 위치문제** — 장 선택 화면의 `레벨 어려움` 및 화면 아래에
  잘린 부분 문자열에 올바른 반칸 간격과 길이별 오버라이드를 적용했습니다.
- **#31 제2차 페이즈 종료 유닛 수 칸 밀림** — 제2차 UI 레코드 20의 제어폭을
  `FC 10`에서 `FC 0B`로 맞춰 `미행동 유닛` 수가 정렬되도록 했습니다.
- **#32 제2차 8화 아군 증원 뒤 멈춤** — 번역으로 이벤트 풀의 위치가 바뀐 뒤에도
  옛 주소를 가리키던 이벤트 포인터를 새 레코드 위치로 재조준했습니다. 249개
  참조를 검사해 248개를 재조정했고, 경계에서 생긴 오인 매치 1개는 건너뛰었습니다.
  최종 이미지에는 잔류하는 잘못된 풀 이벤트 참조가 0개입니다.
- **#33 제2차 7화 승리조건 글자 깨짐** — 승리조건 레코드의 번역 시작 위치를
  `33`에서 `19`로 바로잡아, 이진 제어 프리픽스는 보존하면서 조건 전체를
  `적 요새에 침입하고, 그 후에는 적 전멸.`으로 표시합니다.

## 안전장치와 검증

이벤트 스크립트 감사에 제2차 풀 이벤트 참조 검사를 추가했습니다. 레코드 종단자
바로 앞의 렌더러 데이터(`B1/B3/B4`)를 포인터로 잘못 판정하지 않도록 경계 필터도
넣었습니다. 저장소 감사 도구에 남아 있던 개발자 로컬 절대경로도 제거해 다른
환경에서 릴리즈 검사를 재현할 수 있게 했습니다.

`build_all.py --only 7 --version v0.11.45` 이미지 조립과 `--only 8` 전체 검증을
통과했습니다.

| 검사 | 결과 |
|---|---:|
| 미번역 레코드 | 0 |
| 폭·줄 초과 | 0 |
| 깨진 레코드 | 0 |
| 제2차 풀 이벤트 참조 잔류 | 0 |
| 대사 페이지 최대 바이트 | 127 (한도 127) |
| 글리프·세이브·목록·UI·전투 스크래치 감사 | 통과 |
| CB 및 단독판 xdelta 역적용 검증 | 통과 |
