# v0.11.49 — EX 오프닝·제3차 엔딩 그래픽 패치

이번 릴리스는 GitHub 이슈 [#20](https://github.com/snake7594/srwcb-korean-patch/issues/20)과
[#21](https://github.com/snake7594/srwcb-korean-patch/issues/21)을 다시 추적해,
제2차에서 이미 검증한 **세이브스테이트 VRAM 역검색 → TIM 원본 폭 유지 → 제자리 재압축**
경로로 그래픽 자산을 패치합니다.

## EX 오프닝 — #21

`C_SMAP.BIN` 멤버 40(파일 `0x180412`, 해제 141,216B)을 확정했습니다.

- `高度に発展した科学技術は / 魔術と区別がつかない / アーサー・C・クラーク`
  타자기 프레임 58장을 `고도로 발달한 / 과학기술은 / 마술과 / 구별할 수 없다 /
  아서 C. 클라크`로 교체했습니다.
- 인용문 바로 뒤의 EX 챕터 프롤로그 5장도 함께 한글화했습니다. 인용문만 바꿔
  다음 화면에 일본어가 남던 이전 보류 사유를 해소했습니다.
- 같은 구조로 확인된 멤버 45(파일 `0x1B8811`)의 보조 인용문·내레이션도 함께
  패치했습니다.
- 4bpp TIM의 헤더·CLUT·폭·높이와 58장의 단계별 폭은 바꾸지 않았습니다.

## 제3차 엔딩·예고편 — #20

VRAM 화면 캡처와 멤버별 TIM을 대조해 다음 자산을 한글화했습니다.

- 예고편 본문: 멤버 258·259·261·262. `予告編` 타이틀과 제1화 제목, 제3차
  전쟁의 도입 내레이션, 티탄즈·실종 사건 내레이션을 포함합니다.
- 엔딩 내레이션: 멤버 264·265·266. 이슈 첨부 화면의
  `シュウ＝シラカワ……` 단락(멤버 266)을 포함해 이어지는 결말 문단까지
  한글화했습니다.
- 스태프롤: 멤버 250·251·272. 컴플리트 박스 스태프, 성우·메카 디자인,
  지원 스태프와 협력사 화면을 한글 글판으로 재구성했습니다.
- 모든 대상은 텍스트용 4bpp TIM과 예고편 8bpp 타이틀의 픽셀 블록만 바꿨고,
  원본 그래픽 멤버의 나머지 데이터는 보존했습니다.

### 아직 확인하지 못한 화면

이슈 #20의 첫 번째 이미지에 있는
`シュウ「では、これを見ていただきましょうか」` 한 줄은 이전 전수 조사에 이어
이번에도 `C_SMAP.BIN`·`EFFECT.BIN`·Track 1의 게임 글리프/Shift-JIS 데이터에서
원문 자산을 찾지 못했습니다. 정적 그래픽이 아니라 실행 중 합성되는 화면으로
판단되므로, 이 한 항목은 이 릴리스에서 임의로 덮어쓰지 않고 이슈를 열어 둡니다.

## 구조 검증

- `C_SMAP.BIN`: 9,932,026B, 멤버 297개와 멤버 표 위치 불변
- 대상 멤버의 TIM 목록 전후 동일, 지정한 픽셀 블록 밖 변경 0바이트
- 모든 대상 스트림 재압축 후 해제 왕복 일치 및 원본 스트림 예약 범위 안
- `build_all.py --only 7 --version v0.11.49`: 컴플리트 박스 이미지 조립 성공
- `build_all.py --only 8 --version v0.11.49`: 전체 감사 통과
- 미번역 대사 0, 폭·줄 초과 0, 깨진 레코드 0, 이벤트 포인터 잔류 0
- 최종 이미지: 241,050섹터 / 566,949,600B

배포 파일의 SHA-256은 [`release/SHA256SUMS_v0.11.49.txt`](../release/SHA256SUMS_v0.11.49.txt)에
기록합니다.
