# v0.11.48 — 제2차 페이즈 종료 문구 겹침 수정

이번 릴리스는 GitHub 이슈 [#37](https://github.com/snake7594/srwcb-korean-patch/issues/37)의
제2차 페이즈 종료 화면을 보완합니다.

## #37 원인과 패치

- v0.11.47에서 동적 남은 유닛 수의 제어폭은 `FC 10`에서 `FC 0B`로 올바르게 줄었지만,
  고정 표시 별칭이 `미행동 유닛　　기`로 너무 짧았습니다.
- 그 결과 고정 문구의 `기`가 레테일 위치에 남아 있고, 새 위치로 이동한 숫자가 그 글자를
  덮는 겹침이 생겼습니다.
- 제2차 UI master entry 20의 표시 문구를 제3차·EX에서 검증된 형태와 맞춘
  `미행동 유닛이   기 있습니다`로 교체했습니다. 번역 원문(`korean_text`)과 화면용
  고정 문구(`display_text`)를 모두 기록해 다음 빌드에서 같은 별칭이 되살아나지 않게 했습니다.
- 최종 `SECOND_SECOND.WAR`를 직접 검사하는 게이트에 고정 문구 prefix 검사를 추가했습니다.
  중간 `font_extracted` 파일만 정상이어도 최종 이미지 조립에서 옛 문구가 재사용되는 회귀를
  잡을 수 있습니다.

EX 장 선택 화면은 고정 셀과 `EE FF` 스페이서로 레테일 좌표를 유지합니다. v0.11.47에서
이미 적용된 `슈우편 / 레벨 어려움` 표기를 이번 릴리스에서 임의로 전체 메뉴 위치 이동으로
바꾸지 않았습니다.

## 검증

- `build_all.py --only 3`: 제2차 중간 빌드 성공
- `build_all.py --only 7 --version v0.11.48`: 최종 CB 이미지 조립 성공
- `build_all.py --only 8 --version v0.11.48`: 전체 감사 통과
- 미번역 0건, 폭·줄 초과 0건, 깨진 레코드 0건
- 이벤트 스크립트 포인터 잔류 0건
- 타이틀 메뉴 3종 × 9장 구조·픽셀 검증 통과
- 제2차 페이즈 종료 UI: 고정 문구 prefix 유지, `FC 0B` 1건, `FC 10` 0건
- CB 및 단독판 xdelta 역적용 검증 통과

배포 파일의 SHA-256은 [`release/SHA256SUMS_v0.11.48.txt`](../release/SHA256SUMS_v0.11.48.txt)에
기록합니다.

## 적용 및 상태

릴리즈의 `srwcb-cb-korean-v0.11.48-easy-apply.zip`을 사용하거나, 정품 원본 Track 1·2에
해당 xdelta를 적용하십시오. 원본 이미지와 세이브스테이트를 보관한 뒤 에뮬레이터에서
제2차 페이즈 종료 화면과 EX 장 선택 화면을 재확인해 주세요.

이 릴리스에서 코드·정적 검증으로 확인한 #37의 제2차 문구 겹침은 해결했습니다. 다만
에뮬레이터 전체 플레이 완주 검증은 별도 범위이며, #36 프리징과 #20·#21 이미지 제보,
#27 영어판 요청은 각각 추가 확인이 필요해 열린 상태로 유지합니다.
